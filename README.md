# 捏捏岛 · 日签文案库

这是捏捏岛 App 读取的公开日签内容。修改文案后无需重新打包 App。

## 添加文案

1. 打开 [daily-signs.json](daily-signs.json)，点击 GitHub 页面右上角的铅笔编辑。
2. 在 `entries` 中新增一条，使用没有重复过的 `id`。
3. 把最上方的 `revision` 加 1，然后提交修改。
4. App 打开「今日日签」时会后台检查内容；也可以点「更新文案」立即同步。GitHub 缓存可能让修改稍晚生效。

```json
{
  "id": "pupu-009",
  "character": "pupu",
  "headline": "今天也要开心呀",
  "message": "吃点喜欢的，伸个懒腰，\n给自己一个大大的夸夸！",
  "invitation": "今日宜 · 夸夸自己"
}
```

## 字段与长度

|字段|要求|
|---|---|
|`id`|唯一编号，最长80字；新增内容不要复用已有编号|
|`character`|`pupu` 噗噗山、`juanjuan` 卷卷兽、`doudou` 兜兜兽、`rongrongtu` 绒绒兔、`paopaota` 泡泡獭；省略时所有伙伴可用|
|`headline`|1–12字，直白、积极、可爱|
|`message`|两行，用 `\n` 换行；每行最多24字|
|`invitation`|可省略；填写时1–14字，例如「今日宜 · 夸夸自己」|

文案优先说清楚一件小事、一个鼓励或一个小行动。各位伙伴不需要完全相同；避免空泛绕弯的表达。新增和修改都要增加 `revision`。

本地验证：

```sh
python3 validate.py
```

## App 如何更新

- 在线读取此仓库 `main` 分支的 `daily-signs.json`。
- 打开日签时后台检查，同一次启动内最多每6小时自动检查一次；「更新文案」可主动检查。
- 成功后保存在本机；断网、文件格式错误或旧版本内容不会覆盖已缓存的有效文案。
- 首次离线启动使用安装包中的30条备用文案。

当前仓库仅维护文字内容，不提供 App 安装包或游戏源码。
